# Mounib Aggoun Portfolio Website

A responsive cyberpunk-style portfolio website for Mounib Aggoun, showcasing cybersecurity, penetration testing, Linux, OSINT, automation, and a featured Smart City project.

## ✨ What This Portfolio Includes

- A futuristic hero section with a profile image and animated UI elements
- An About section focused on cybersecurity, penetration testing, Linux, automation, and OSINT
- A featured project section for Smart City linked to the GitHub repository
- A skills section covering cybersecurity, penetration testing, Linux, automation, OSINT, and AI
- A certifications section featuring the Red Hat Linux Fundamentals certification
- An Experience & Education section showing the bachelor’s degree in progress
- A contact section with GitHub, LinkedIn, email, and Instagram links

## 🛠️ Technologies Used

- HTML5 for semantic page structure
- CSS3 for the cyberpunk theme, layout, and animations
- Vanilla JavaScript for interactions and animated effects
- GSAP and ScrollTrigger for motion effects
- Google Fonts: Orbitron, JetBrains Mono, and Inter

## 🎨 Design Style

The site uses a dark neon-inspired visual system with:
- Cyan, pink, and green accent colors
- Glass-like panels and glowing UI elements
- Smooth scrolling and animated transitions
- A responsive layout for desktop and mobile devices

## 🚀 Getting Started

Open the project in a browser directly or serve it locally:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
